# 所有相邻采样帧独立差分

## 动机与计算

旧方案将区间内多帧差分求和，中间项抵消，只剩端点差。当前方案直接复用 FPS 采样得到的 N 帧，对统一缩放、归一化后的帧计算 R_i = F_(i+1) - F_i，共 N−1 个独立三通道差分，不累加，不进行区间补采样或二次解码。

## 输入输出与排列

RGB 按两帧一块，K = ceil(N/2)。第 k 个 RGB 块后放 R_(2k) 和 R_(2k+1)，仅放实际存在的差分。四帧对应：
RGB(F0,F1), R0, R1, RGB(F2,F3), R2。

每个差分在时间维复制为深度 2，复用冻结的 RGB Patch Embedding。残差 grid 时间维为 N−1，交错 grid 时间维为 K+N−1。RGB 奇数末帧仍复制补齐，不为该复制帧生成差分。单帧没有残差。

RGB 时间戳取其两帧中点，差分时间戳取对应相邻帧中点。块内差分与该 RGB 块时间戳相同。Prompt、视觉序列和 DeepStack 均使用同一排列。连续时间编码保持移除状态。

## 训练、推理与兼容性

训练目标、输出格式、残差 LN/gate/modality embedding 和共享 Patch Embedding 参数形状不变。训练及评测共用 prepare_rit_video_inputs，并同步修改序列说明 Prompt。

配置版本为 shared_rgb_patch_adjacent_v3；移除 residual_num_diffs。旧 RIT checkpoint 因序列语义和 Prompt 不同，由版本检查拒绝直接加载。新实验从原始 Qwen3-VL 权重启动，新版 Stage 1 可接续新版 Stage 2。

固定总预算 B、每块最低 token 数 m 时，偶数采样帧上限为 2*floor((floor(B/m)+1)/3)。实际预处理始终按 K+N−1 个块检查预算和计算空间分辨率。

## 影响与待验证假设

移除二次解码，但视觉块从旧版 2K−1 增加到偶数帧时的 3K−1。固定总视觉预算下，空间分辨率或最大采样帧数会下降。显存、吞吐和定位指标需用户执行正式实验确认。

需验证独立相邻差分是否保留有用的短时运动变化，以及收益是否抵消空间细节减少。建议比较 RGB-only、旧区间端点差、当前所有相邻差分；分别控制总 token 预算和采样帧数，记录实际空间分辨率与帧数，避免混淆计算量变化。

## 静态与局部检查范围

检查奇偶帧、单帧、批内不同视频的差分数量和排列、时间戳、预算上限。局部合成输入检查不代表模型训练或评测已完成。
